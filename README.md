# Drug AI — Research & Development

An AI-powered research assistant designed to analyze medical reports and scientific research papers.

## Project Vision

Build an AI system that can extract and analyze information about drugs, diseases, proteins, targets, and side effects from scientific literature.

## Development Phases

- **Phase 1:** Medical report and research paper analysis.
- **Phase 2:** Drug knowledge graph.
- **Phase 3:** Advanced AI for scientific research and drug discovery.

## Phase 1 — Current Progress

- [x] PDF text extraction using PyMuPDF
- [x] Text cleaning
- [x] Reference filtering
- [x] Sentence-aware text chunking
- [x] TF-IDF evidence retrieval
- [x] Extractive question answering using RoBERTa
- [x] Basic answer rejection mechanism

## Technologies

- Python
- PyMuPDF
- NLTK
- Scikit-learn
- PyTorch
- Hugging Face Transformers

## Current Status

Phase 1 prototype is under development.

## Disclaimer

This project is for educational and scientific research purposes. It is not a clinical decision-support system and does not provide medical advice.
